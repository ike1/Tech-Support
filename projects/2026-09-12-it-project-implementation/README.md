# IT project implementation and rollout

**Week of 2026-09-12**  
Turn an approved IT improvement into a controlled implementation plan with owners, milestones, testing, and a go-live decision.

## Scenario

You are implementing a small internal IT service change for a 150-user organization and must deliver it with minimal disruption.

## Objective

Practice a small, realistic support workflow that can be completed, reviewed, and improved in one week.

## Checklist

- [ ] Define the problem, in-scope users and systems, out-of-scope work, assumptions, dependencies, and measurable outcomes.
- [ ] Create a work breakdown structure, milestone plan, RACI, risk register, and stakeholder communication schedule.
- [ ] Specify a test plan with acceptance criteria, pilot group, rollback steps, support readiness, and change-approval evidence.
- [ ] Run a tabletop go-live review and record the go/no-go decision, lessons learned, and 30-day benefits follow-up.

## Deliverable

A concise implementation charter, rollout plan, risk register, test evidence, and go-live checklist.


## Success measure

Every milestone has an owner and acceptance criterion; all high risks have a mitigation or explicit approval.

## Notes

- Do not include passwords, personal data, or production secrets in this project.
